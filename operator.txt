operator
---------
1)arthimatic

->increment
post-increment (after)
first value will be assigned
then increments

eg:
let a=10;
console.log(a) //10
console.log(a++) //10
console.log(a++) //11

pre-increment (before)
first increment will done
then value will be assigned

eg:
let b=10;
console.log(b)//10
console.log(++b) 11

->assignment
=,+=,-=,*=,%=,/=

eg:
let c=10
console.log(c) //10
console.log(c +=10) //20

3)relational operator
--> <,>,<=,<=,==,===,!=
console.log(10==10) //true
console.log(10=='10') //true
console.log(10==='10') //false
console.log(10===10) //true

4) logical operator
-> AND(&&),OR(||),NOT(!=)

5) ternary operator
-> will accept three operands
syntax:
(condition) : true-statement : false-statement

eg:-
(5<10): console.log("hello"): console.log("bye")
